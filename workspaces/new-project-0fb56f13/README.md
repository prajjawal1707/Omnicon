# Expense Tracker

A simple Python expense tracker that allows users to add, edit, and delete expenses, as well as generate monthly expense summaries and category-wise reports.

## Features

* Add, edit, and delete expenses
* Monthly expense summaries
* Category-wise reports
* Input validation
* Unit tests

## Usage

1. Run the program using `python main.py`
2. Choose an option from the menu to perform the desired action
3. Follow the prompts to input data
4. The program will display the result of the action

## Requirements

* Python 3.x
* No external dependencies required
